# Version 4: precision, recall and F1 by test set

Model alone. Gold test: 169 papers, 476 results, human labels. Bronze holdout: 576 windows, machine labels. Mix: the two pooled by counts. Read after the choice from stored results; no new read of the gold test.

Gold P is the scope precision: finds outside gold count as wrong, except correlations in papers with results. Gold P strict counts every find outside gold as wrong. Both are lower bounds, because the coders followed statcheck's scope.
